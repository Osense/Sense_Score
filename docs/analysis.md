# Guitar Pro 5 기능 분석 (참고용)

출처: 설치 폴더의 공개 매뉴얼 `Help/GuitarPro_EN.pdf`와 설정/데이터 파일의 평문 내용. 실행 파일은 분석하지 않았다.

## 구조 요약
- 멀티트랙 악보 편집기 (트랙 최대 256개). 모든 트랙이 같은 마디 수와 박자를 공유해 동기화를 보장한다.
- 입력: 키보드(숫자패드), 마우스(지판), MIDI 키보드. 편집 커서를 쓰고, 악보를 클릭해도 음표가 실수로 추가되지 않는다.
- 재생: 구간 선택 재생, 반복, 스피드 트레이너(시작/목표/증가 템포), 상대 템포 ×0.25~×2, 메트로놈, 카운트 다운, 스텝 모드.
- 믹서: 트랙별 솔로·뮤트·볼륨·팬·리버브 등. 재생 중에도 변경 가능.
- 표시: 확대 30~200%, 페이지/가로/세로 모드, 트랙별 표시 토글.
- 도구: 스케일 도구, 코드 다이어그램, 지판/건반 표시, 튜너, 마법사(일괄 편집).
- 입출력: MIDI, MusicXML, ASCII, PDF 등.
- 안전장치: 자동 백업(10분), Undo/Redo.

## 학생용 작곡 앱에 가져올 것 / 바꿀 것
| 가져올 것 | 이유 |
|---|---|
| 트랙 믹서 (솔로/뮤트/볼륨) | 파트별로 들어보며 편곡 학습 |
| 상대 템포, 반복, 스피드 트레이너 | 연습과 확인 |
| 메트로놈, 카운트 인 | 박자 감각 |
| 스케일 도구 | 피아노 롤에서 스케일 음 강조, 틀린 음 방지 |
| Undo/Redo, 자동 저장 | 학생의 실수에 대한 안전망 |
| 클릭이 곧바로 편집이 되지 않는 안전한 커서 | (다르게) 피아노 롤에서는 클릭=입력이 더 직관적 |

| 바꿀 것 | 방향 |
|---|---|
| 타브 중심 | 피아노 롤 중심 |
| 복잡한 메뉴와 단축키 | 큰 버튼, 도움말 툴팁, 한국어 우선 |
| 데스크톱 전용 | 설치 없는 웹 앱 |

## 먼저 만들 것 (제안 순서)
1. 피아노 롤: 그리드, 음표 추가/삭제/이동/길이 조절, 격자 스냅
2. 재생: 사운드폰트 신디사이저, 재생헤드, 템포
3. 트랙: 여러 트랙, 악기 선택, 솔로/뮤트/볼륨
4. 저장: .mid 불러오기/내보내기, 로컬 자동 저장
5. 학습 보조: 스케일 강조, 코드 추천, 메트로놈/카운트 인
6. 선택: 악보(오선보) 미리보기

## 열린 질문
- 대상 학생 연령대 (초/중/고)
- 태블릿 터치 지원 범위
- 교사용 기능(과제 제출, 공유)이 필요한지
